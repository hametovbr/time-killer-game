# MOB CANNON — Game Design Document

Рабочее название: **Mob Cannon** (рус. «Пушка толпы»).
Платформа: браузер (мобильный портрет в приоритете, десктоп тоже). Без рекламы, без доната, без таймеров ожидания.

## 1. Ядро в одну фразу
> Веди пушку пальцем, стреляй толпой через ворота-множители и снеси вражескую базу раньше, чем враги дойдут до твоей.

## 2. Управление
- **Зажал и ведёшь** (палец/мышь) — пушка едет по рельсу за пальцем и стреляет, пока палец прижат.
- **Тап по кнопке чемпиона** — выпустить гиганта, когда шкала заполнена.
- Клавиатура (десктоп): ←/→ или A/D — движение, Space — стрельба, E — чемпион.

## 3. Игровое поле (портрет, логика 400×720)
```
 [ ВРАЖЕСКАЯ БАЗА  HP ]   ← цель
   враги идут вниз ↓
 [×2]      [÷2]   [×3]   ← ряды ворот (2–4 ряда)
   ═══ стена 25 ═══       ← препятствия
      ⟋ спиннер ⟍
 [×3]  [×2]
   юниты летят вверх ↑
        ◉ пушка (рельс)
 [   МОЯ БАЗА  ♥♥♥  ]
```

## 4. Механики (оптимальный набор — 8 элементов)
| # | Элемент | Правило | Вводится |
|---|---|---|---|
| 1 | Ворота **×N** (зелёные) | каждый прошедший юнит превращается в N | ур. 1 |
| 2 | Вражеская база | HP; каждый юнит −1, чемпион −20 | ур. 1 |
| 3 | Враги | идут волнами вниз, юнит+враг = оба исчезают; дошёл до базы — −1 HP базы | ур. 3 |
| 4 | Ворота **÷N** (красные) | проходит только каждый N-й юнит | ур. 4 |
| 5 | Чемпион | шкала копится от выстрелов; гигант (HP 30) топчет врагов, в ×-воротах «рожает» юнитов | ур. 6 |
| 6 | Подвижные ворота | ворота ездят влево-вправо | ур. 8 |
| 7 | Стена с HP | поглощает юнитов, пока счётчик не обнулится | ур. 11 |
| 8 | Спиннер | вращающаяся балка уничтожает юнитов | ур. 13 |
| + | Вражеский гигант | толстый враг с HP, давит юнитов | ур. 10 (боссы) |
| + | Золотые ворота ×5 | редкие, узкие | ур. 20 |

Почему так: один жест + одна «математика» (×/÷) — понятно за 2 секунды; всё остальное — модификаторы *траектории* (куда целиться) и *темпа* (как быстро), а не новые правила управления. Новый элемент появляется каждые 2–3 уровня в начале и разреженнее потом.

## 5. Структура уровней — «пила»
- Каждый **5-й** уровень — **БОСС**: крепость с ×2.5 HP, гиганты, щит из стен/спиннера.
- Уровень после босса — **передышка** (сложность −2 шага).
- Уровни **7, 17, 27…** — **бонус «Золотая лихорадка»**: 15 сек, врагов нет, вместо базы — копилка; каждый долетевший юнит = монета.
- Уровень длится 25–60 сек (босс ~60). Сессия из 4–6 уровней ≈ 3–5 минут.
- После 30 уровня генератор продолжает бесконечно (детерминированный сид = номер уровня, поэтому уровень N всегда одинаковый).

### Формулы
- `d(n)` (сложность) = `n − 2·[n−1 — босс] + 3·[n — босс]`
- Скорость врагов: `45 + 1.4·d` (cap 88), интервал волн: `max(1.9, 3.8 − 0.06·d)` сек, размер волны: `min(18, 3 + 0.42·d)`.
- HP базы = `8 выстр/с × ожидаемый_множитель_пути × 0.5 × (1 + 0.03n) × целевое_время`; целевое время 16 → 40 сек (босс 32 → 55).
- Адаптивное облегчение: каждое поражение на уровне уменьшает размер волн врагов на 10% (до −40%); при поражении всё равно даются монеты пропорционально нанесённому урону.
- Баланс проверен ботом (`npm run sim`): бот средней точности с ожидаемыми апгрейдами проходит ~80% уровней 1–40 с первой попытки и ~95% уровней 1–20; без апгрейдов уровни 10+ почти не проходятся — мета-слой реально нужен.
- Апгрейды увеличивают поток быстрее, чем растёт `d` — «награды опережают вызов».

## 6. Мета-слой
- **Монеты** за уровень: `30 + 8n`, × звёзды (1★ ×1, 2★ ×1.5, 3★ ×2), × апгрейд «Доход».
- **Звёзды**: по остатку HP своей базы (≥70% — 3★, ≥35% — 2★).
- **4 апгрейда** (цена растёт ×1.45):
  - Скорострельность (+12% / уровень)
  - Прочность базы (+3 HP)
  - Заряд чемпиона (−10% к нужному числу выстрелов)
  - Доход (+15% монет)
- Нет энергии, нет таймеров, нет «посмотри рекламу ×2».

## 7. Game feel
- Ворота «пульсируют» и выкидывают всплывающее «×2» при срабатывании.
- Частицы-«пыль» при столкновении юнит/враг, вспышка и тряска при ударе по базе, hit-stop 80 мс при ударе чемпиона и разрушении базы.
- Синтезированные звуки WebAudio: тон «тика» растёт с потоком; аккорд победы.
- Вибрация на Android при важных событиях. Опции: звук, вибрация, уменьшить тряску.

## 8. Сохранение
`localStorage` (`mobcannon.save.v1`): уровень, монеты, апгрейды, звёзды по уровням, настройки, статистика. Сохраняется после каждого уровня и покупки. PWA-манифест + service worker — игра ставится на домашний экран и работает офлайн.

## 9. Технологии
Vite + TypeScript, Canvas 2D, без игровых движков. Логика (`src/game/sim.ts`) отделена от рендера — есть headless-симулятор с ботом (`npm run sim`) для проверки баланса. Деплой — GitHub Pages через Actions.
