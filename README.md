# Lane Squad 🪖

**Та самая игра из рекламы — только честная.** Отряд, три полосы, ворота-множители и зомби. Без рекламы, без доната, без таймеров. Работает прямо в браузере (и офлайн, если «установить» на домашний экран).

▶ **Играть:** https://hametovbr.github.io/time-killer-game/

## Как играть
- Держи палец (мышь) над полосой — отряд перебегает туда. Стрельба автоматическая.
- Синие ворота **+N / ×N** добавляют солдат, красные **−N / ÷N** отнимают. По воротам с 🎯 можно стрелять — число растёт.
- Расстреливай ящики: 🔫 — оружие лучше, ⭐ — ранг (урон) солдат.
- Зомби забирают солдат при контакте. В конце — босс.
- ПК: ←/→ или A/D, 1/2/3 — полоса, Esc — пауза. `?autoplay` в адресе — игра играет сама.

## Разработка
```bash
npm install
npm run dev        # локальный сервер
npm run build      # сборка в dist/
npm run sim -- 1 40 0.8   # headless-прогон уровней ботом для проверки баланса
```
Стек: Vite + TypeScript + Canvas 2D, без движков. Логика (`src/game/sim.ts`) отделена от рендера (`src/game/render.ts`).
Деплой — Actions собирает `dist/` и публикует в ветку `gh-pages` при пуше в `main`.

> История: v1 «Mob Cannon» (пушка как в Mob Control) заменена на v2 «Lane Squad» — см. `docs/GDD.md`.
