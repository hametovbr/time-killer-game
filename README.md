# Mob Cannon 🎯

**Та самая игра из рекламы — только честная.** Пушка, толпа и ворота-множители. Без рекламы, без доната, без таймеров. Работает прямо в браузере (и офлайн, если «установить» на домашний экран).

▶ **Играть:** https://hametovbr.github.io/time-killer-game/

## Как играть
- Зажми и веди пальцем (или мышью) — пушка едет за пальцем и стреляет.
- Проводи юнитов через зелёные ворота **×N**, объезжай красные **÷N**.
- Твоя толпа уничтожает врагов 1 к 1; снеси вражескую базу раньше, чем враги дойдут до твоей.
- С 6-го уровня копи шкалу 👑 и выпускай чемпиона.
- ПК: ←/→ или A/D — движение, пробел — огонь, E — чемпион, Esc — пауза.

## Разработка
```bash
npm install
npm run dev        # локальный сервер
npm run build      # сборка в dist/
npm run sim -- 1 40 0.8   # headless-прогон уровней ботом для проверки баланса
```
Стек: Vite + TypeScript + Canvas 2D, без движков. Логика (`src/game/sim.ts`) отделена от рендера (`src/game/render.ts`).
Деплой — GitHub Pages через Actions при пуше в `main`.
